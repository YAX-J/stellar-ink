# 高保真原型

本目录保存星笺的单文件高保真原型，是前端视觉和交互的唯一基准。

## 文件

- `index.html`：包含页面结构、样式和原型交互，可直接用浏览器打开。

## 使用方式

修改前端页面前，先对照原型确认布局、颜色、字体、圆角、留白与动效。原型用于设计校准，不承载真实业务数据，也不作为生产构建入口。

## 约束

- 保持深色星空、缓慢、诗意的整体气质。
- 不引入亮色大色块或与现有设计无关的组件风格。
- 前端实现应优先复用 [`stellar-ink-web/src/styles/tokens/variables.css`](../stellar-ink-web/src/styles/tokens/variables.css) 中的语义变量。
- 若正式页面与原型不一致，应先确认设计变更，再同步修改原型和 Vue 实现。
