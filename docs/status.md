## 1. 平台与基础设施

- 后端微服务化完成：网关 `:8080`（路由 / CORS / Sa-Token 鉴权 / Sentinel）+ user `:8101` +
  content `:8102` + ai `:8107`，注册与配置走 Nacos，Python `stellar-ink-ai :8200` 仅内网可达。
- 鉴权：Sa-Token JWT 无状态；**JWT 可撤销**（登出/改密把令牌摘要写 Redis，网关路由前校验，fail-closed）；
  角色三档 READER ⊂ AUTHOR ⊂ ADMIN，写进 JWT extra（**改角色后必须重新登录才生效**）。
- Redis 已接入：`RedisUtils` + 故障回源的 `RedisCache`。**已进缓存**：登录失败计数与账号锁定、JWT 撤销、
  公开作者摘要、公开文章/笔记列表与详情、标签、统计、评论、友链、流星、回声。
  **刻意不进缓存**：完整用户资料、草稿、私有/审核数据、JWT 原文、浏览闸门、点赞明细、持久计数。
- 空闲保活（本机跨公网时代的对策，现本机连线仍保留）：Druid 代码级保活 + 双保活心跳、
  Lettuce 三处加固。成因与验收见 `architecture/README.md` §空闲保活。
- 启动期 JCE 预热：把「重启后第一个鉴权请求卡 5 秒」挪到启动（`JceWarmupRunner`，两份实现）。
  见 `architecture/README.md` §重启后第一个请求为什么慢 5 秒。
- 本机开发默认连本机 Redis + MySQL、Nacos 留远端；**本机库与服务器库是两份数据，互不同步**。

## 2. 后端功能

- 开放注册（`POST /auth/register`，注册即登录、角色固定 READER）；账号页支持改密、登出、ADMIN 角色管理。
- 内容域：文章 / 技术笔记 / 流星 / 回声 / 星链 / 标签 / 搜索 / 统计，多作者归属（AUTHOR 只能维护自己的内容，
  ADMIN 可管理全部；友链是全局数据）。
- 阅读体验一期：浏览量按天去重（登录）与点赞一人一赞、`orderBy` 三档（latest / hottest / longest）。
- 文章评论一期：公开列表 + 登录发表 + 作者或 ADMIN 软删除（正文 ≤1000 字）。
- 技术笔记一期 + 复核：`note` 表与 `/notes` 接口、公开/私有两档可见性（**私有一律 404**，ADMIN 也不越权）、
  180 天时效由 `verified_at` 实时派生、`/notes/mine?view=review` 四档筛选与就地「仍然有效」。
- 作者申请闭环：`PUT /user/role-apply`（提交/覆盖）+ `/cancel`（撤回），审核队列复用 `GET /user/list`，
  通过与驳回都走 `PUT /user/{id}/role`。
- 头像：图片 + 底字双轨；`stellar.ink.storage.type` 两档（`local` 本地磁盘 / `cos` 腾讯云 + CF Worker）；
  服务端改名 + 魔数校验 + 1MB 双拦。详见 `architecture/avatar-minio.md`。
- 友链审核闭环：公开只返回已接入项，ADMIN 在账号页通过/驳回。

  它同时管新鲜度与**隐私窗口**（笔记转私有后不再被回答，此前要重启进程才生效）；

  流式状态机抽成可多实例的 `composables/useQaStream.js`（浮层与深读页互不干扰），

- **助手浮层已按司职收口，并新增两个出口**（2026-10-05）：`/ai/agent/ask` 加 `agent`
  （缺省 `searcher`；另有 `answerer` 无工具纯生成、`verifier` 确定性核验）——提示词、工具白名单与预算
  都变成**司职数据**，未知司职报错不猜；新增 `POST /ai/agent/verify`（引用核验）与
  `POST /ai/me/providers/models`（拉供应商模型清单）。关键取舍：两者都**不进调用账、不占配额**

  核验只做确定性那一半（**`ok` 只表示「引用能对上原文」，不等于「答案已核实」**，语义核验未做）；
  拉清单**绝不回落站长全局密钥**（地址由用户填，借出全局 Key 等于任何登录用户都能把它发到自己的地址），
  地址只允许公网 —— 站长拉 `127.0.0.1` 自建端点会被 400 拒，要支持得另开 ADMIN 出口。
  ⚠️ Python 与 ai-service 都改了，**必须重启才生效**（不重启时「拉取模型」显示「拉不到」是预期）。
- **真实模型已端到端实测**（2026-10-01）：`chat` / `embedding` / `rerank` 三个角色各打通过一次真实调用
  （`uv run python scripts/provider_smoke.py`，3/3），并在**同一条检索编排**上跑出真实数字 ——
  dense recall@1 **0.8083**（同一份黄金集上，Fake 伪向量只有 0.075）、hybrid **0.8583** / MRR **1.0**，
  于是「向量通路与混合检索确实有用」第一次有了量化答案。数字、读数与实测口径见

  writing_suggest / agent / eval）+ `GET /ai/admin/usage/summary`（ADMIN）——
  回答「谁用了多少、花了多少、失败率多少」。成本按**角色单价快照**算，
  没配单价 / 上游没回报 token 的调用**分别计数**并如实暴露，绝不当 0 混进金额。
- **E3-2 AI 配额与并发已落地**（2026-10-01）：用户（每日调用数 + token）、角色（每日调用数）、

  Redis 不可用时放行并告警（配额不是安全边界）。
- **E3-3 MCP 工具服务已落地**（2026-10-01）：`POST /mcp` 用 JSON-RPC 2.0 暴露只读工具

  **schema 之外的参数一律拒绝**，身份只从签名的 `X-AI-*` 头来 —— 这是「客户端不能靠构造参数扩权」的落点。
- **E3-4 观测出口已落地**（2026-10-01，最小形态）：`GET /ai/admin/trace/{traceId}` 一个 traceId
  看完整条链路 —— Java 侧调用账（谁、多少 token、成功失败）+ Python 侧事件（检索 / 工具 / 模型含上游状态码）；
  **Python 挂了仍回账**并按 `notes` 说明原因。Python 侧的链路缓冲有界、**只存结构不存内容**。
  跨副本回放与长期留存需要 OTel/Langfuse，**要你拍板**（已写进 `ai/status.md`）。
- **B/C 收口第一刀已交付**（2026-10-01）：模型调用加了**退避重试**（只重试值得重试的失败）、
  **嵌入缓存**（整库嵌入从「每个策略一遍」降到「全局一遍」）、并把**额度用尽**与**瞬时限流**分开
  —— 前者不重试，且消息会直说「每日上限 + 重置时间 + 重试无用」。
- ⏳ **需要你出手的一件事（不是代码问题）**：`openrouter` 免费档是**每模型每日 50 次**，
  今天 embedding / rerank 两条腿的额度已用尽（`Remaining: 0`，次日 UTC 零点重置）。
  这挡住了**标准五组的 dense 三行**与 **`minDenseScore` 标定**。
  两个选择：给这两条腿换付费/自建模型（上游原话「Add 10 credits → 1000 次/日」），或等重置后再跑。
  **标定工具已经写好并自测过**（`scripts/calibrate_dense_score.py`：dense-only 扫真实分数分布、
  给推荐点、额度不足时如实报错而不是给出假分布），额度一恢复就能跑出数字。
- ⏳ **另一件环境动作**：Qdrant 冒烟需要先开隧道（本机 `127.0.0.1:6333` 当前不可达），
  跑一次 `uv run python scripts/qdrant_smoke.py` 即可把 B 阶段从「代码完成」变成「实测通过」。
- 边界：AI 算法一律在 Python 侧，Java 只做鉴权/配额/协议/降级（见 `AGENTS.md` §5）。

## 5. 下一步与候选（做完之前别当已做）

- **E4-11 已落地（增量失效）→ LLM Wiki 这条线闭环**：文章改了不必整库重跑 ——
  `GET /ai/admin/wiki/stale` 把库里存的主张锚点交给 Python 比对当前语料，三种状态**分开报**：
  `current` 不用动、`stale`（段落内容变了）该**重建**、`orphan`（段落没了）该**清理**
